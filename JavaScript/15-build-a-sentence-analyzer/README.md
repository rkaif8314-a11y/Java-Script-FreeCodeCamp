# Build a Sentence Analyzer

This FreeCodeCamp JavaScript exercise builds a sentence analyzer that counts vowels, consonants, punctuation marks, and words.

## Concepts Practiced

- Functions
- Strings
- Loops
- `for...of`
- `includes()`
- `toLowerCase()`
- `trim()`
- `split()`
- Template literals
- Counters

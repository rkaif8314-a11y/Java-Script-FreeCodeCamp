# Build a String Formatter

This FreeCodeCamp exercise demonstrates common JavaScript string methods for cleaning, transforming, and formatting text.

## Concepts Practiced

- `trim()`
- `trimStart()`
- `trimEnd()`
- `toUpperCase()`
- `toLowerCase()`
- `slice()`
- String indexing
- String concatenation
- Template literals and `console.log()`

## Key Techniques

`trim()` removes whitespace from both ends of a string.

`trimStart()` removes leading whitespace, while `trimEnd()` removes trailing whitespace.

`toUpperCase()` and `toLowerCase()` change the letter case of a string.

`slice()` can be combined with string indexing and concatenation to create formatted text, such as converting `camelcase` into `camelCase`.

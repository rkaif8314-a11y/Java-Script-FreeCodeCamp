# Build a Library Manager

This FreeCodeCamp JavaScript exercise manages a book catalog and demonstrates how to transform, filter, and summarize array data.

## Concepts Practiced

- Arrays of objects
- Arrow functions
- `map()` to transform catalog entries
- `filter()` to find books by an exact author name
- `reduce()` to calculate the total number of pages
- `join()` to format lists as strings
- Template literals
- Accessing object properties
- Console output

## Expected Result

The total page count for all books in the provided catalog is **2512 pages**.

# Build a Space Mission Roster

This FreeCodeCamp JavaScript exercise manages a space crew and applies several array-processing techniques and algorithms.

## Concepts and Algorithms Practiced

- Objects and arrays
- Linear search to detect duplicate crew IDs
- Array copying with `slice()`
- Array insertion and removal with `splice()`
- Index validation
- Bubble sort in descending priority order
- Filtering crew members by EVA eligibility
- Chunking an array into smaller groups
- `for` loops and `for...of`
- Helper functions and return values

## Important Notes

- `sortByPriorityDescending()` mutates the array passed to it.
- `printCrewSummary()` sorts a copy so the supplied crew order is preserved.
- The EVA list is filtered first and then sorted by priority.

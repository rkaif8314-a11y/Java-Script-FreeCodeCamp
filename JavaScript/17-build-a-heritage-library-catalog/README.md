# Build a Heritage Library Catalog

This FreeCodeCamp JavaScript exercise parses raw book-card strings into catalog objects, searches and groups entries, validates records, exports data, and finds publication-year statistics.

## Concepts Practiced

- String parsing with `split()` and `trim()`
- Arrays and objects
- Functions and loops
- Missing-data handling
- Case-insensitive search with `toLowerCase()` and `includes()`
- Grouping data by decade
- `Math.floor()`
- Object key enumeration with `Object.keys()`
- Entry validation with the `in` operator
- JSON export with `JSON.stringify()`
- CSV formatting
- Template literals and string methods
- Minimum and maximum tracking with `Infinity`

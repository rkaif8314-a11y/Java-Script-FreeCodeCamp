# Build a JavaScript Trivia Bot

A simple JavaScript trivia bot that introduces itself and shares three facts about its favorite programming language.

## Concepts Practiced

- Variables with `let`
- String concatenation
- Variable reassignment
- `console.log()`
- Using variables inside generated messages
- Creating and updating a reusable `codingFact` variable

## Bot Details

- **Name:** kafbot
- **Location:** botStore
- **Favorite Language:** JavaScript

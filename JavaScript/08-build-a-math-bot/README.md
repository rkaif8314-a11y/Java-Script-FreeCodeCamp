# Build a Math Bot

This FreeCodeCamp exercise practices the JavaScript `Math` object and common Math methods.

## Concepts Practiced

- `Math.random()`
- `Math.floor()`
- `Math.ceil()`
- `Math.round()`
- `Math.max()`
- `Math.min()`
- Random number generation
- Template literals
- `console.log()`

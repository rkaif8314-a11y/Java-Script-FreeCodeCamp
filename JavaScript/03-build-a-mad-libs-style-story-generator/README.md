# Build a Mad Libs Style Story Generator

This exercise creates two stories using JavaScript variables and template literals.

## Concepts Practiced

- `let` variables
- Variable reassignment
- Template literals using backticks
- Variable interpolation with `${variable}`
- `console.log()`
- Reusing variables to generate different stories

## Key Technique

Instead of joining text with many `+` operators, template literals allow variables to be inserted directly into a string:

```javascript
`Hello ${name}!`
```

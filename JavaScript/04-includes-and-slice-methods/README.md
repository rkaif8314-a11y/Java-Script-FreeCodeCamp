# Includes() and Slice() Methods

This FreeCodeCamp workshop demonstrates how to use JavaScript's `includes()` and `slice()` string methods.

## Concepts Practiced

- `String.includes()`
- Case-sensitive string searching
- `String.slice()`
- Positive and negative indexes
- Template literals
- `console.log()`
- Boolean results from string methods

## Key Techniques

The `includes()` method checks whether a string contains a specified substring and returns `true` or `false`.

```javascript
fccSentence.includes("freeCodeCamp");
```

The `slice()` method extracts a portion of a string without modifying the original string.

```javascript
message.slice(11, 23);
message.slice(-1);
```

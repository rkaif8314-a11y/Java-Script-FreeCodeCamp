# Build a Wildlife Tracker

This FreeCodeCamp JavaScript exercise works with animal objects and demonstrates how to read, add, update, delete, and check object properties.

## Concepts Practiced

- Objects
- Object properties
- Arrow functions
- Property access
- Dynamic property access
- Adding properties
- Updating properties
- `delete`
- `hasOwnProperty()`
- `console.log()`

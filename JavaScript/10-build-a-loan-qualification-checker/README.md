# Build a Loan Qualification Checker

This FreeCodeCamp JavaScript exercise checks loan eligibility based on annual income and credit score.

## Concepts Practiced

- Constants
- Functions
- Parameters and return values
- `if`, `else if`, and `else`
- Comparison operators
- Logical `&&` operator
- Conditional decision-making
- `console.log()`
